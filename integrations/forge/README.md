# AIFRED ↔ FORGE bridge

This directory is AIFRED's credential-free integration boundary for FORGE. The production API remains the authority for operational data; local mirrors are generated by `node integrations/forge/bridge/export.mjs` and are not a second execution path.

## Endpoints

- Production base: `https://www.north3rnlight3r.com`
- Health: `GET /health`
- Models: `GET /v1/models`
- Site export: `GET /api/v1/admin/export/site`
- Track analysis export: `GET /api/v1/admin/export/tracks`

Admin exports require the existing bearer session. Supply it to the bridge process as `AIFRED_ADMIN_SESSION_TOKEN`; it is never written to disk.

```sh
node integrations/forge/bridge/export.mjs all
tools/link-forge-integration.sh /path/to/FORGE/integrations/aifred
```

The mirror retains `exports/latest` and completed runs in `exports/history` until `AIFRED_FORGE_ACTIVE_LOG_LIMIT_MB` (default 25 MB) is reached. Older completed runs rotate only after verified local archival; the newest run and latest snapshots remain active. Export/archive data is ignored by Git; manifests and schemas are tracked.

No FORGE ToolRouter implementation exists in this repository, so this bridge exposes declarative capabilities only. A FORGE installation should register these endpoints through its own authority/router layer.

See [FORGE Integration](../../docs/FORGE_INTEGRATION.md) and [Archive Guide](../../docs/ARCHIVE_GUIDE.md).
