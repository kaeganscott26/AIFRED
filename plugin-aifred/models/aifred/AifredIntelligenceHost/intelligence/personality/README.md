# intelligence/personality

Purpose: define AIFRED's conversational voice independently from evidence and analysis policy.

Personality may control:
- tone;
- producer/engineering vocabulary;
- concision/detail preference;
- humor/energy;
- conversational cadence.

Personality may not:
- change measurements;
- weaken uncertainty rules;
- invent problems or confidence;
- override reference compatibility;
- promote guesses to facts;
- change memory retention;
- grant tools or permissions.

Keep personality documents human-readable and versioned. A provider switch must not silently change the core behavioral/evidence contract.
