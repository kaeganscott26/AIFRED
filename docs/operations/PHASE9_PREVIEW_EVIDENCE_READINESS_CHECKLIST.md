# Phase 9 Preview Evidence Readiness Checklist

This is a pre-preview checklist to confirm the future evidence template is ready. Do not fill this with fake evidence. Do not invent preview URLs. Do not record secrets.

- [ ] Evidence template exists.
- [ ] Preview run date/time field ready.
- [ ] Branch field ready.
- [ ] Commit SHA field ready.
- [ ] GitHub Actions run field ready.
- [ ] Cloudflare preview URL field ready.
- [ ] Homepage status field ready.
- [ ] Catalog status field ready.
- [ ] Download flow status field ready.
- [ ] API route fields ready.
- [ ] Console/network error fields ready.
- [ ] Production domain changed yes/no field ready.
- [ ] Rollback needed yes/no field ready.
- [ ] Final preview result field ready.
- [ ] Screenshot/notes fields ready.

## Evidence Safety Rules

- Do not record secret values.
- Do not infer preview pass/fail before an actual preview exists.
- Do not claim production was unchanged without checking the production domain during the actual preview window.
- Do not reuse stale GitHub Actions, Cloudflare, console, or network observations as current evidence.
