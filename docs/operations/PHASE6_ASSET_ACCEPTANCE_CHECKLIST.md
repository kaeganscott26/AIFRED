# Phase 6 Asset Acceptance Checklist

This checklist blocks merge to `main` until the repository asset decision is explicitly approved.

- [ ] Duplicated website media has been reviewed.
- [ ] Repo size impact has been accepted or rejected.
- [ ] R2 or release-storage long-term plan has been accepted.
- [ ] No Git LFS conversion happens in Phase 6.
- [ ] No media deletion happens in Phase 6.
- [ ] No history rewrite happens in Phase 6.
- [ ] Merge to `main` remains blocked until the asset choice is approved.
