Android package is `com.aifred.admin`, version 2.3.0 (code 243). Windows Desktop uses WinForms. macOS Desktop is built locally from tracked source; its generated `.app` is ignored.

Only Android has the user-entered admin command parser. Desktop offline access covers local archives, not live website administration.
