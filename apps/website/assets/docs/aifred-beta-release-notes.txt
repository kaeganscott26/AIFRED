AIFRED Official Beta Release Notes
=================================

Current plugin version: 0.3.6
Current release tag example: v0.3.6-installer-ai-alias

AIFRED is a real-time mix diagnostic VST3 built around Halo analysis, reference alignment, comparison metering, and request-driven AI guidance grounded in current DSP measurements.

Key features:
- Tone, Width, Loudness, Punch, Dynamics, correlation, crest, and transient analysis.
- Analyze, Reference, and Compare modes.
- Canonical interpreted analysis snapshot shared by meters and chat context.
- Session and minute-history candlestick metering.
- Five personal reference lanes plus reference-pool overlays.
- Mix A / Mix B comparison workflow.
- Scrollable chat using current mix and reference context.
- Default local AI through AIFRED Engine and Ollama model aifred:latest.
- Optional OpenAI route using gpt-5.6-luna when configured.
