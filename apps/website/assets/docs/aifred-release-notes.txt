AIFRED v0.3.6 Release Notes

Current build:
- JUCE VST3 plugin version 0.3.6.
- Real-time Halo analysis for tone, width, loudness, punch, correlation, dynamics, and reference alignment.
- Canonical interpreted analysis snapshot shared by the UI and Ask AI context.
- Analyze, Reference, and Compare modes.
- Session and minute-history candlestick metering.
- Five personal reference lanes plus reference-pool overlays.
- Separate Mix A and Mix B comparison routes.
- Scrollable request-driven chat with real DSP/reference context.
- Default local AI route through AIFRED Engine -> Ollama -> aifred:latest.
- Optional OpenAI route through https://api.openai.com/v1/responses using gpt-5.6-luna when configured.
- Windows installer, Windows uninstaller, Windows VST3 zip, and macOS pkg release targets.
- Public website currently presents AIFRED as a $5 one-time beta purchase with no subscription or recurring charge.
- Tokenized download delivery can use the AIFRED_DOWNLOADS Cloudflare R2 binding.
- Catalog audio uses AIFRED_WEBSITE_ASSETS R2 first with local development fallback.
- Android admin app remains owner-only and is not a public release artifact.
