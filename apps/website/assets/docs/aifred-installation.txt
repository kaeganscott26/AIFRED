AIFRED Installation

Windows
-------
Current Windows release artifacts:
- AIFRED-VST3-Setup.exe
- AIFRED-Uninstall.exe
- AIFRED-VST3-windows.zip

The one-click installer installs the VST3 and AIFRED Engine, writes default local Ollama configuration, registers engine startup, starts the engine silently, and checks local readiness.

Primary paths:
- C:\Program Files\Common Files\VST3\Aifred.vst3
- C:\Program Files\Aifred\bin\AifredEngine.exe
- %AppData%\Aifred\user_settings.json

Default local AI route:
AIFRED VST3 -> http://127.0.0.1:8787 -> http://127.0.0.1:11434 -> aifred:latest

macOS
-----
Current macOS release artifact:
- AIFRED-VST3-macOS.pkg

Install Ollama first, then run the pkg.

The package installs:
- /Library/Audio/Plug-Ins/VST3/Aifred.vst3
- /Library/Application Support/Aifred/bin/AifredEngine
- /Library/Application Support/Aifred/config/config.json
- /Library/Application Support/Aifred/setup-aifred-local-ai.sh
- /Library/Application Support/Aifred/AIFRED Engine Control.command
- /Library/LaunchAgents/com.aifred.engine.plist

The LaunchAgent starts the engine at login. Use AIFRED Engine Control.command to start or repair local AI, restart the engine, stop it for the current login session, or show gateway health.

The current macOS package is not yet signed or notarized.

OpenAI
------
When OpenAI is selected and an API key is configured, AIFRED uses:
- Endpoint: https://api.openai.com/v1/responses
- Default model: gpt-5.6-luna

Do not store live API keys in website files or committed repository text.

Website And Catalog
-------------------
The canonical website/backend source lives under apps/website.
Catalog metadata lives at apps/website/assets/data/beat_catalog.json.
Catalog audio is served through /api/v1/assets/audio/catalog/<file>.
The backend reads from the AIFRED_WEBSITE_ASSETS R2 binding first and keeps local static files as a development fallback until R2 parity is verified.
